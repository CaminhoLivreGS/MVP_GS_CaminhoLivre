# Fotos ilustrativas dos relatos simulados

MOCK: os 32 relatos de demonstração (`relatos_seed.json`) não têm foto real. Para o mapa público e o
Painel ADM mostrarem como o produto funciona, cada relato simulado recebe uma destas fotos, todas
de **domínio público ou CC0** do Wikimedia Commons (as mesmas de `dataset/commons/`, reduzidas para 640 px).
Na API e nas telas elas aparecem marcadas como "foto ilustrativa". Relatos reais enviados pelo app usam a
foto da pessoa (já com rostos e placas borrados).
